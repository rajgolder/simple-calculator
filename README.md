# Simple Python Calculator

A straightforward, beginner-friendly command-line calculator built with Python. This project is a great starting point for understanding how functions, user input, and basic loops work in programming.

## ✨ Features

- **Basic Operations:** Can add, subtract, multiply, and divide two numbers.
- **Error Checking:** Won't crash if you try to divide a number by zero.
- **Keeps Running:** Let's you make multiple calculations one after another without closing the program.
